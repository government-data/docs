## Perfilado (nivel 1)

Antes de las reglas se describe cada columna. Patrón: `9` = dígito, `A` =
mayúscula, `a` = minúscula, `·` = espacio, `{n}` = repeticiones.

| Campo               | Nulos | Distintos | Patrón más frecuente | Participación |
| ------------------- | ----- | --------- | -------------------- | ------------- |
| Celular             | 3,1 % | 9.480     | `39{9}`              | 94,2 %        |
| Correo              | 8,4 % | 8.910     | `a{n}@a{n}.aaa`      | 88,0 %        |
| Código de ciudad    | 0,2 % | 412       | `9{8}`               | 97,5 %        |
| Código de actividad | 1,6 % | 286       | `9{4}`               | 81,3 %        |
| Fecha de nacimiento | 0,4 % | 7.950     | `9{4}-99-99`         | 99,6 %        |

**Cómo se lee.** Un código de actividad con solo 81 % en el patrón de cuatro dígitos sugiere
códigos guardados como número que perdieron el cero inicial: un problema de
tipo, sistémico, que se corrige en la extracción.

la regla está mal planteada. Las reglas más bajas se revisan con su dueño
antes de corregir miles de registros.
